# Sculptify Catalog Handoff

The reusable catalog listing is drafted in [PREBUILT_BUSINESS_LISTING.md](./PREBUILT_BUSINESS_LISTING.md).

## Immediate hosting blocker
GitHub Actions configure-pages fails with `Create Pages site failed: Resource not accessible by integration`. Repository administrator must open Settings > Pages and choose GitHub Actions as the build source. Then rerun the deploy workflow.

## Before marking the catalog listing ready
- Confirm the live demo HTTPS address.
- Capture screenshots of desktop and mobile views from that deployed site.
- Verify bookings, owner login, AI, checkout and data isolation; the existence of source code is not proof of working production integrations.
- Approve the proposed sales pricing and licensing terms.
- Add the final domain to the canonical URL and sitemap, then verify indexing.

## Next site starter intake
Record: business name, industry, city/service area, owner-approved branding, core customer action, essential pages, product/service catalog, payment provider and hosting budget. Use separate credentials and separate deployments for each business.
